# python_func_programming_exercises

a collection of basic exercises on functional programming concepts done in Python during my university course. publishing here mainly to keep as a reference for myself

## topics/concepts covered

- first-class functions
- pure functions
- recursion
- higher-order functions
- function composition
- referential transparency
- lazy evaluation
- pattern matching
- type systems
- concurrency and parallelism
- lambda functions
- filter(), map(), reduce()

## getting started

### dependencies

- Python 3.13.5

### installation

- clone the repository or download the code files

### run

- since it's just a collection of scripts, run whatever Python script from any of the directories in whatever way you prefer
